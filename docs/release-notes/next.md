# Make place details easier to scan

- Place details show linked airfields as cards below the map and mark those
  in your passports. Where next? is now in the page header, and ownership
  and edit history appear beside the copy and move controls on large screens.

- Data checks and aircraft Expenses can suggest missing landing or takeoff
  fees based on earlier movements at the same airfield. Reviewers can
  record or link an expense, confirm no fee was due, or defer the suggestion.
