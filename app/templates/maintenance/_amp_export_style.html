{# Self-contained styling for the AMP export document — shared by the on-screen preview (amp_export.html) and the standalone PDF template (amp_export_pdf.html, which does not extend base.html and so has no Bootstrap/icon-font CSS available). Styled after real shop-produced Part-ML AMPs (black header bars, a merged block-number gutter column, single-answer Yes/No cells) rather than the plain regulatory illustrative table — content still follows the AMC2 ML.A.302 block structure, see docs/maintenance_import.md. The @page rules only take effect for paged media (WeasyPrint's PDF render, and a browser's own print-to-PDF of the preview page) — harmless on screen. The running header uses CSS GCPM (position: running() / element() / counter()), which WeasyPrint supports natively. #}
